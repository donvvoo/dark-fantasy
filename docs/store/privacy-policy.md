# 어비스 키우기 개인정보처리방침 / Privacy Policy

시행일 / Effective date: 2026-11-23

## 한국어

**어비스 키우기**(이하 "게임")는 이용자의 개인정보를 수집하지 않습니다.

1. **수집하는 정보:** 없습니다. 게임은 이름, 이메일, 위치, 연락처, 기기 식별자 등 어떤 개인정보도 수집하지 않습니다.
2. **기기에 저장되는 정보:** 게임 진행 상황(스테이지, 레벨, 재화, 설정)은 이용자의 기기 안에만 저장됩니다. 이 정보는 외부로 전송되지 않으며, 앱을 삭제하면 함께 삭제됩니다.
3. **네트워크 사용:** 게임은 인터넷 연결 없이 동작하며, 어떤 서버와도 통신하지 않습니다.
4. **광고·분석·결제:** 현재 버전에는 광고, 분석 도구, 인앱 결제가 포함되어 있지 않습니다. 이후 추가되는 경우 이 방침을 갱신하고 앱 업데이트 전에 공지합니다.
5. **아동의 개인정보:** 게임은 어떤 연령의 이용자에게서도 개인정보를 수집하지 않습니다.
6. **문의:** 개인정보 관련 문의는 Google Play 스토어의 개발자 연락처로 보내 주세요.

## English

**Raise Abyss** ("the Game") does not collect personal information.

1. **Information collected:** None. The Game does not collect names, email addresses, location, contacts, device identifiers or any other personal data.
2. **Information stored on the device:** Game progress (stage, levels, currencies, settings) is stored only on the player's device. It is never transmitted and is removed when the app is uninstalled.
3. **Network use:** The Game works offline and does not communicate with any server.
4. **Ads, analytics, purchases:** This version contains no advertising, analytics or in-app purchases. If any are added, this policy will be updated before the app update that adds them.
5. **Children:** The Game collects no personal information from users of any age.
6. **Contact:** Please use the developer contact listed on the Google Play store page.
